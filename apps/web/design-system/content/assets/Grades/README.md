# Grade Icons

Source: <https://github.com/ppy/osu-web/tree/7fda4c70d15007d6700ec3520520e3a3c00b7229/public/images/badges/score-ranks-v2019>

osu!'s score grade badges: SS and S, their silver Hidden or Flashlight versions SSH and SH, then A, B, C and D. They show a score's grade on score cards and beatmap leaderboards. Keep their colours; chart marks for grades use the `score-grade-*` tokens.
