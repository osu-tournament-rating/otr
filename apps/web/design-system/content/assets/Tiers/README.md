Tier badges, one per tier and subtier: Elite Grandmaster (no subtiers), then Grandmaster, Master, Diamond, Emerald, Platinum, Gold, Silver and Bronze, each as `<Tier>1.svg`, `<Tier>2.svg` and `<Tier>3.svg`.
