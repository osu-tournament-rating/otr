The o!TR mark: a disc cut into crescents, in brand blue `#4D94FF` (close to the dark theme's `primary`).

- `small.svg`: the mark alone. The site header shows it at 36px, linking home ("o!TR home"); it grows 5% on hover.
- `full-logo.svg`: the mark with the wordmark in near-black `#101010`, for light grounds (`background`, `card`).
- `full-logo-dark.svg`: the mark with the wordmark in white, for dark grounds.
- `full.svg`: the mark with the wordmark in `#050505`, for light grounds.
- `otr-logo-2.svg`: the mark in near-black `#101010` at 15% opacity, a watermark for light grounds.

Never recolour the blue, redraw the mark or set it on a busy image.
